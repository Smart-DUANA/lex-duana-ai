# Changelog

All notable changes to the Lex Duana plugin are listed here. Versions follow semantic versioning; the version of the manifest, of this file and of the skill archive are always the same.

## 1.0.0

- First public version.
- Connector to the Lex Duana server (`.mcp.json`, server name `lex-duana`), with sign-in by Lex Duana account.
- Skill `lex-duana`: when to use the `lex_*` tools, how to cite a text and its version, how to keep the number of calls low, with five reference files loaded on demand.
